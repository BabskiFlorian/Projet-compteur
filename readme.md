**Projet "Compteur" : Suivez vos morts dans Elden Ring.**

## Lien de la page :
https://babskiflorian.github.io/Projet-compteur/index.html

"Compteur" est une simple application web (HTML, CSS, JavaScript) pour les joueurs d'Elden Ring.
 Elle permet de compter vos décès via des boutons d'ajout et de retrait, avec un affichage du total.
  Ce petit projet illustre l'interactivité web basique et rend hommage à la difficulté du jeu.
